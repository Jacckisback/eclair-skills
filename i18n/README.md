# Translations of the skills

`skills/` (French) is the source. Everything under `translations/<lang>/` is generated by `python3 scripts/build_skills.py` from:

- `i18n/fr/templates.json` — French skeletons and shared sentences;
- `i18n/<lang>/templates.json` — the same keys, translated;
- `i18n/<lang>/skills_*.json` — per skill: `title`, `goal`, `wp`, `model`, `procedure`, `invariant`, `pos`, `neg`;
- `i18n/<lang>/foundation/` — the hand-written foundation skills, one file per unique source file (see `i18n/foundation-map.json`).

To get the French fields to translate: `python3 scripts/build_skills.py --export-source i18n/src` (not committed).

When a French skill changes, update its entry in every `i18n/<lang>/` file, then rebuild, re-run the checks and re-sign.

## Rules for translators
- Translate naturally and professionally, as a native technical writer would. Keep the instruction style of the source (imperatives / infinitives, short sentences). Do not add, remove or soften content. Do not add commentary.
- NEVER translate or alter: text inside backticks, file paths, code, URLs, skill names (`eclair-...`), product and plugin names (WordPress, WooCommerce, Yoast, Stripe, Éclair CMS, MCP...), HTTP terms (GET, POST, CSRF, CSP, JSON-LD, hreflang), `e()`, `Store`, `$ctx['data']`, PR #19.
- Placeholders in curly braces such as {name}, {goal}, {contract}, {wp_line} must be kept EXACTLY as they are (same spelling, same braces), each one present the same number of times as in the source.
- Keep Markdown structure exactly: headings, numbering, bold markers, lists, line breaks, « » quotes may become the target language's usual quotes.
- Terminology: "noyau" = the CMS core (EN core, ES núcleo, DE Kern, IT core, PT núcleo). Keep the word "skill" untranslated. "brouillon" = draft. "fonction" (of the CMS) = feature/extension depending on context ("fonction" installed in site/extensions = extension). "droit" = permission/right. "paquet" = package.
- Do not promise results: keep every caution ("not production-ready", "never", "measured, not promised") as strong as in the source.
- Portuguese = European Portuguese. Spanish = neutral Spanish from Spain. German: use neutral infinitive/imperative instructions, no "Sie"/"du" addressing where avoidable.
