# Validation plan — Sharing previews

## Data model
Sharing title, description, sharing image.

## Expected implementation
Check the sharing tags and the image generated by the core, test the preview on the main platforms.

## Tests to plan
1. Nominal: Test the preview of a post and of a page.
2. Refusal check: A page without a dedicated image keeps a correct default preview.
3. Invariant: The sharing image contains no personal data and no misleading text.
4. GET/HEAD: public cache only without session state or sensitive data; canonical, HTTP status, SEO and GEO unchanged or improved.
5. POST: never any shared cache; CSRF, TLS, permissions, attempt limiting, idempotency. Do not run if the core does not officially support it.
6. Activation and deactivation: content is preserved and public routes are removed without any leak.
7. Checks: native validator, PHP and HTTP tests, budgets; record the commands run, their results and what was not tested.

## Proof of availability
Status of the feature or extension, CI logs, test matrix, rollback procedure, and refusal of any unverified promise.
