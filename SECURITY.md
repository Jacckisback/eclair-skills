# Sécurité / Security

**FR —** Ne publiez pas de vulnérabilité dans une issue publique. Utilisez le signalement privé GitHub (onglet *Security* → *Report a vulnerability*) de ce dépôt. Pour une faille du noyau Éclair CMS, signalez-la sur le dépôt [`Jacckisback/eclair-cms`](https://github.com/Jacckisback/eclair-cms).

Portée : les skills sont des guides ; `examples/extensions/catalogue-demo` est un exemple en lecture seule ; `examples/extensions/member-directory` et `core-patch/` sont des **prototypes expérimentaux non qualifiés pour la production**. La CI de ce dépôt ne constitue pas un audit de sécurité.

**EN —** Do not open public issues for vulnerabilities; use GitHub private vulnerability reporting on this repository (core CMS issues go to `Jacckisback/eclair-cms`). Skills are guides; the member-directory example and `core-patch/` are experimental prototypes, not production-ready. CI here is not a security audit.
